I'm Mohamed Ali Laabar, usually known online as Dali, a cybersecurity and cloud engineering student. I write about the things I'm learning and breaking down — SOC/defensive security, reverse engineering, networking, web security, and cloud security — with the practical side in focus: hands-on labs, following real traces and captures, and taking systems apart until they make sense.

This blog collects longer technical notes and lab write-ups across those areas, along with shorter notes as I work through new material.

What I write about:

- SOC operations and defensive security
- Reverse engineering and low-level software internals
- Networking and protocol analysis
- Web application security
- Cloud security and infrastructure
- Systems and OS security
- Shorter notes and write-ups
